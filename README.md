# Debriefer

Multi-source research orchestration engine with Wikipedia RSP-based reliability scoring, phased execution with early stopping, per-query cost control, and AI synthesis. 60+ built-in source integrations.

<!-- badges -->

## Installation

```bash
npm install debriefer
```
